# Automata storefront

The landing page for [Automata on Gumroad](https://markdanila1.gumroad.com). It lists every published product and links each one to its Gumroad page.

## How it stays up to date

A GitHub Actions workflow ([publish.yml](.github/workflows/publish.yml)) runs every 30 minutes, on every push to `main`, and on demand from the Actions tab. Each run:

1. reads the profile and products from the Gumroad API (`scripts/sync.mjs`)
2. copies each product cover and the profile picture into `public/data/`
3. writes `public/data/products.json`, which `index.html` renders from
4. publishes `public/` to GitHub Pages

Create, edit or unpublish a product on Gumroad and the page follows on the next run.

## Setup

- Repository secret `GUMROAD_ACCESS_TOKEN`: from Gumroad Settings → Advanced → Applications
- Settings → Pages → Source: **GitHub Actions**

`index.html` is generated by `landing/build.py` in the main project. Product details written by hand (specs, discount codes) live in its `CURATED` list; anything new on Gumroad appears automatically with a "New" label.
